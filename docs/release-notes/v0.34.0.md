IDE Synth Bay (formerly HDD Synth Pro) emulates an IDE hard disk and a CD-ROM drive from a microSD card. This release adds an experimental fast mode for the SD card on the PCB, which reads from the card twice as fast, and a console command that measures the card. Windows 98 now runs on the drive with DMA.

## Which file to flash

Put the board in its bootloader (hold BOOTSEL while plugging it in, or type `b` on the serial console), then copy one UF2 onto the drive that appears.

| File | What it is |
|---|---|
| `hddsynthpro-pcb-drive-v0.34.0.uf2` | The drive for the **IDE Synth Bay PCB**: hard disk, CD-ROM drive or both, the SD card on 4-bit SDIO. |
| `hddsynthpro-bb48-drive-v0.34.0.uf2` | The same for the **Olimex RP2350-PICO2-BB48** (the card on SPI). It also runs on the PCB, more slowly. |
| `hddsynthpro-bb48-listen-v0.34.0.uf2` | Listen only, for recording a real drive's bus; never drives a pin. |

## Added

- **The SD card's high-speed mode (experimental, PCB only).** Put `sd_high_speed = on` in `HDDSYNTH.INI`. At start-up the drive switches the card into its high-speed mode and checks which timings read right, then reads from the card at 40 MHz instead of 20. The card on its own reads 17.7 MB/s instead of 9.2. If the card can't, or ever gives a bad read, the drive goes back to the normal speed by itself until it's switched off. The serial console's `S` shows which (`clock=high-speed` or `clock=25mhz`). Off by default until it has been tested on more cards.

  How much faster the PC gets depends on what held it back. Copying 200 MB from the CD-ROM to the hard disk under Windows 98 with DMA, in an Athlon XP PC:

  | Mode | Time |
  |---|---|
  | PIO | 4 min 20 s |
  | DMA | 1 min 16 s |
  | DMA, the card in high-speed mode | **1 min 1 s** |

  In PIO under DOS the PC's own handling of each sector sets the pace, so it gains only a few percent there.

- **Console `G`: how fast the card is.** It reads the served image straight from the card, with no PC involved, and prints the speed and a checksum of the whole image. With the scratch `HDDBENCH.IMG` served it also writes 4 MB and reads it back.

## Tested

- **Windows 98 SE** installed from its CD (served by the drive's CD-ROM) onto a blank 4 GB image, and run with DMA for the disk and the CD-ROM: the first operating system to use the drive's DMA. Windows 98 needs `MaxPhysPage=20000` in `SYSTEM.INI` on a PC with more than 512 MB of memory, as it would with any disk.
- The benchmark disk on the Athlon XP PC, with the card at both speeds.
- Through a USB IDE adapter: the read and write tests, and the speed of every way of answering the bus, as in v0.33.2.

## Known limits

- Everything in v0.33.2's notes still applies.
- High-speed mode is new and has been tested on one card; a long card soak is still to come before it's on by default.
