IDE Synth Bay (formerly HDD Synth Pro) emulates an IDE hard disk and a CD-ROM drive from a microSD card. This release fixes the one known problem in v0.33.1's block mode; nothing else changes.

## Which file to flash

Put the board in its bootloader (hold BOOTSEL while plugging it in, or type `b` on the serial console), then copy one UF2 onto the drive that appears.

| File | What it is |
|---|---|
| `hddsynthpro-pcb-drive-v0.33.2.uf2` | The drive for the **IDE Synth Bay PCB**: hard disk, CD-ROM drive or both, the SD card on 4-bit SDIO. |
| `hddsynthpro-bb48-drive-v0.33.2.uf2` | The same for the **Olimex RP2350-PICO2-BB48** (the card on SPI). It also runs on the PCB, more slowly. |
| `hddsynthpro-bb48-listen-v0.33.2.uf2` | Listen only, for recording a real drive's bus; never drives a pin. |

## Fixed

- **The drive's identity block after a PC turns block mode on.** The drive describes itself to the PC in a 512-byte identity block that ends in a checksum. Once the PC had turned block mode on, the drive updated the block but not its checksum, so a PC (or an operating system) that read the block again and checked it would have seen it as damaged. PCs rarely check it, and none seen so far did; it is right now.

## Tested

- Through a USB IDE adapter: the read and write tests, and the speed of every way of answering the bus, as in v0.33.1.

## Known limits

- Everything in v0.33.1's notes still applies, apart from the checksum above.
